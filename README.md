# Менеджер задач в браузере

Учебный проект на Python: персональный To-Do list с сохранением задач в JSON-файл и локальным веб-интерфейсом.

## Возможности

- Открывается локально в браузере по адресу `http://127.0.0.1:8000`.
- Спокойное пастельное оформление без выбора действий цифрами в консоли.
- Добавление задачи с названием, описанием, сроком выполнения и приоритетом.
- Просмотр всех, активных или выполненных задач через кнопки-фильтры.
- Сортировка при просмотре: активные задачи выше выполненных, ближайший срок выше позднего, высокий приоритет выше среднего и низкого.
- Отметка задачи как выполненной одним нажатием кнопки.
- Удаление задачи с браузерным подтверждением.
- Автоматическая загрузка из `tasks.json` и сохранение после изменений.
- Валидация названия, даты в формате `ДД.ММ.ГГГГ` и приоритета.
- Поиск по названию.
- Красная подсветка просроченных активных задач, если такие задачи уже есть в файле данных.

## Запуск веб-версии

```bash
python3 web_todo.py
```

После запуска откройте в браузере:

```text
http://127.0.0.1:8000
```

Файл `tasks.json` создаётся автоматически при первом сохранении задачи.

## Консольная версия

Консольный вариант также сохранён:

```bash
python3 todo.py
```
