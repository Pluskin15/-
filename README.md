# Менеджер задач в браузере

Учебный проект: персональный To-Do list с готовым локальным HTML-приложением, которое открывается без запуска Python.

## Возможности

- Основной вариант открывается как обычный файл: [`todo_app.html`](todo_app.html).
- Спокойное пастельное оформление без выбора действий цифрами в консоли.
- Добавление задачи с названием, описанием, сроком выполнения и приоритетом.
- Просмотр всех, активных или выполненных задач через кнопки-фильтры.
- Сортировка при просмотре: активные задачи выше выполненных, ближайший срок выше позднего, высокий приоритет выше среднего и низкого.
- Отметка задачи как выполненной одним нажатием кнопки.
- Удаление задачи с браузерным подтверждением.
- Автоматическое сохранение в localStorage браузера после изменений.
- Валидация названия, даты в формате `ДД.ММ.ГГГГ` и приоритета.
- Поиск по названию.
- Экспорт и импорт JSON-файла `tasks.json` через кнопки в интерфейсе.
- Красная подсветка просроченных активных задач, если такие задачи импортированы из файла.

## Запуск без Python

Откройте файл [`todo_app.html`](todo_app.html) двойным кликом или через браузер: `Файл → Открыть файл`.

Python, сервер и установка библиотек для этого варианта не нужны. Данные сохраняются в localStorage конкретного браузера. Чтобы перенести задачи, используйте кнопки **Экспорт JSON** и **Импорт JSON**.

## Дополнительные варианты

Если нужен режим с Python, в проекте также оставлены прежние версии:

```bash
python3 web_todo.py
python3 todo.py
```
