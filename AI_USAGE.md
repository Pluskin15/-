# Документированное использование ИИ

В проекте использовался ИИ-инструмент ChatGPT для подготовки фрагментов кода и проверки подхода к обработке ошибок.

## Примеры запросов

1. «Сгенерируй функцию Python для проверки даты в формате ДД.ММ.ГГГГ и сравнения с текущей датой, чтобы прошедшие даты отклонялись».
2. «Покажи пример безопасного чтения и записи JSON-файла с обработкой FileNotFoundError, JSONDecodeError, PermissionError и OSError».
3. «Сгенерируй функцию подтверждения удаления задачи в консольном приложении, принимающую ответы да/нет».

## Как результат использован в коде

- Проверка даты реализована в функции `parse_due_date`.
- Обработка ошибок JSON-файла реализована в функциях `load_tasks` и `save_tasks`.
- Подтверждение удаления реализовано в функции `confirm_deletion`.

Скриншоты диалога можно добавить в отчёт отдельно, если этого требует формат сдачи работы.
